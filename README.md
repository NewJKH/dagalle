# 다갈래 (Dagalle)

> AI that designs your trip from start to finish — powered by data, built for real travel.

**다갈래** is an AI-driven travel planning platform for Korean domestic travel.  
Enter your preferences and duration, and the AI generates a complete itinerary with routes,  
restaurant recommendations, multi-modal transportation, and full cost breakdowns.

## Key Features
- 🤖 AI itinerary generation (Claude API)
- 🗺️ Google Maps integration — routes, places, travel time
- 🍽️ Data-driven restaurant recommendations (rating + sentiment analysis)
- 🚗 Multi-modal transport — car, subway, bus, train
- 💰 Automated cost calculation — fuel, transport, food
- 👥 Group travel — invite, share, collaborate

**Stack:** Spring Boot · MySQL · AWS · React · React Native · Claude API · Google Maps API
